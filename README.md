1. Импорттау

import React, { useState } from 'react';

React кітапханасы мен useState функциясы қосылады. useState Email мәнін сақтауға көмектеседі.

import {
  StyleSheet,
  Text,
  View,
  TextInput,
  TouchableOpacity,
  Alert,
} from 'react-native';

Бұл компоненттер экранды құруға, мәтін енгізуге, батырмаларды басуға және хабарламалар көрсетуге арналған.

2. Email мәнін сақтау

const [email, setEmail] = useState('');

* email — пайдаланушы енгізген Email мекенжайы.
* setEmail — Email мәнін жаңартатын функция.
* useState('') — бастапқы мәннің бос екенін білдіреді.

3. Email тексеру

const handleReset = () => {
  if (!email) {
    Alert.alert('Қате', 'Email енгізіңіз!');
    return;
  }
};

handleReset функциясы батырма басылған кезде орындалады. Егер Email бос болса, экранда қате туралы хабарлама шығады.

4. Қалпына келтіру хабарламасы

Email енгізілген жағдайда, пайдаланушыға сәтті орындалғаны туралы хабарлама көрсетіледі.

Alert.alert(
  'Сәтті',
  'Құпия сөзді қалпына келтіру сілтемесі email-ге жіберілді!',
  [
    {
      text: 'Жақсы',
      onPress: () => navigation.navigate('Login'),
    },
  ]
);

Пайдаланушы «Жақсы» батырмасын басқанда, Login бетіне өтеді.



5. Экран элементтері

* View — экран элементтерін орналастырады.
* Text — тақырыптар мен мәтіндерді көрсетеді.
* TextInput — Email енгізуге мүмкіндік береді.
* TouchableOpacity — батырмаларды басуға мүмкіндік береді.
* Alert — хабарлама терезесін ашады.

6. Дизайн және стиль

StyleSheet.create() арқылы экранның сыртқы көрінісі бапталған.


Project/
├── src/
│   └── screens/
│       └── ForgotPasswordScreen.tsx
├── App.tsx
└── README.md

ForgotPasswordScreen.tsx файлына құпия сөзді қалпына келтіру бетінің коды жазылады.

App.tsx файлында навигация бапталады, ал README.md файлында жоба туралы ақпарат беріледі.

Бұл — ұсынылатын файл құрылымы. Оны өз жобаңыздың нақты құрылымына қарай өзгертуге болады.

Бұл жоба React Native арқылы құпия сөзді қалпына келтіру экранын жасауға арналған. Жоба барысында useState, TextInput, TouchableOpacity, Alert және StyleSheet компоненттері қолданылды. Сонымен қатар, пайдаланушының енгізу әрекетін тексеру және Login бетіне қайта өту қарастырылды.

Жоба мобильді қосымшаның интерфейсін құру және React Native негіздерін үйрену дағдыларын дамытуға көмектеседі.
